Scryboard App Runner — proof of concept

Installed apps keep running in the background and are remembered across restarts. Supports a small set of pre-approved packages and prompts for any secrets an app needs. Still missing: code signing.

📂 Open folder is where an app puts anything it made for you. Give a file → (only shown when an app needs one) is the other direction — files you hand to it.

Secrets are stored securely on this computer, the same way your Scryboard token is — never sent anywhere except to whatever this app actually calls. Files stay on this computer too; they're never uploaded to Scryboard.

This is your own app, so its code already lives on this computer — nothing gets downloaded. Point at the folder holding it (the one with scryboard.json in it) and it runs from there. Edit your code any time; the next run picks it up.

Pick new files for this app any time — this replaces what it currently has for that input, and the app re-reads it on its next run.
